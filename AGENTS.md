# Правила проекта
Прочесть README, TODO, CHANGELOG, docs/WORKFLOW.md, docs/BUILD.md и действующее русское ТЗ. Сверить путь, Git status, историю, origin и удалённый HEAD. Сохранить чужие изменения. База — актуальная main, обновление только fast-forward. Работать в codex/<задача>.

Согласовать поведение, записать требования и критерии, реализовать, собрать и проверить в WSL. Поддерживать устойчивые номера требований и TC, маркеры [R]/[N]/[U], ревизии, карту источников, TODO и обе версии CHANGELOG. Новые решения явно передавать владельцу.

Осмотреть diff, добавить конкретные файлы, разделить независимые изменения. Подписывать каждый Conventional Commit на английском через Windows Git и точный UNC этой же копии. Проверить user.name, user.email, user.signingkey, gpg.format=ssh, gpg.ssh.allowedSignersFile. Только существующий ключ, commit -S, verify-commit HEAD и статус G в log. При ошибке остановиться, сохранить индекс и описать причину. После коммита проверить дерево и режимы в WSL.

Push, land, PR, теги, релизы, Pages, выбор основной ветки и настройки GitHub выполняет владелец. После «слил» сверить фактические HEAD и успешный CI для точного SHA. Передать ветку, SHA, результаты, пропуски и открытые проверки.
