# Linux на STM32F429I-DISCO
[English](README.en.md)

Цель — загрузить встраиваемый Linux на Discovery и подтвердить запуск на плате. Первая итерация отделяет проверку инструментов и доступа по SWD от загрузки ядра. Решения по загрузчику, ядру и корневой ФС принимает владелец.
