# История изменений
[English](CHANGELOG.en.md)

## Unreleased
В компактную сборку BusyBox включён интерактивный top. На STM32 через SSH проверены обновление экрана, возврат по q и размер оболочки.

Демонстрационная сборка принимает пароль user для UID 1000, запрещает root по SSH и хранит отдельный ключ Ed25519 в секторе 23. После сборки доступны BIN и адресный Intel HEX.

После холодного старта компактный BusyBox и нативный TCC доступны в /bin. Проверены сборка Hello World на плате, SSH и двусторонний SCP.

Загрузчик во Flash штатно включает 168 МГц. После кнопки RESET и полного выключения питания проверены SSH с терминалом и передача 16 КиБ через SCP.

Проверен временный профиль 168 МГц без записи Flash: вся SDRAM, загрузка Linux, SSH и двусторонний SCP.

После снятия питания подтверждены старт из Flash, интерактивный терминал SSH и повторная передача 16 КиБ с совпадающими SHA-256.

Linux 6.14.5 с Dropbear и SCP помещён во внутреннюю Flash вместе с загрузчиком DEFLATE. Выполнен вход по ключу с ПК и проверен SHA-256 файла 16 КиБ после передачи на плату и обратно.

На Linux 6.14.5 с LAN8720 проверен двусторонний ICMP через eth0. Добавлены профиль и исправление выравнивания RX для Cortex-M.

MAC принял два кадра с проверенным FCS через PC4/PC5 без пайки.

Проверены статические уровни PC4/PC5 до подключения входов RMII.

Подтверждена подача такта LAN8720 на MAC через PA1 при программно освобождённом INT1 гироскопа.

Добавлены ТЗ 1.0, проверка связанного Cortex-M4 ELF без платы и протокол чтения идентификатора MCU через SWD.

TC-03 пройден на плате. Проверены маркер исполнения, адрес аппаратной остановки и полное восстановление 4 КиБ внутренней SRAM.

На MB1075 B-01 проверены инициализация FMC и выборочная запись и чтение внешней SDRAM.

Проверены все 8 МиБ внешней SDRAM. Собраны пробные ядро Linux 6.14.5 и DTB для Discovery.

Linux 6.14.5 запущен на Discovery из SDRAM через SWD. TC-05 подтверждён журналом ранней консоли на COM21.

TC-06: минимальный /init из встроенного initramfs запущен на Discovery. Windows получила на COM21 сообщение после проверки PID 1.

TC-07 пройден. Команда uname -r, отправленная в BusyBox hush через COM21, вернула 6.14.5 и новое приглашение.
