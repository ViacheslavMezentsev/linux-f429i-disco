# Сборка и проверка

## Чистая локальная копия
В WSL нужны Git, GNU Make, Python 3.8+ и GNU Arm Embedded (arm-none-eabi-gcc и binutils в PATH). Проверено с GCC 10.2.1. При необходимости пакет Ubuntu называется gcc-arm-none-eabi.

```sh
src=~/github/ViacheslavMezentsev/linux-f429i-disco
dst=$(mktemp -d)
git clone --no-local -b codex/bringup "$src" "$dst/repo"
cd "$dst/repo"
make check
arm-none-eabi-readelf -hl out/probe.elf
git status --short
```
Ожидаются ноль замечаний по ТЗ, TC-01 PASS и пустой status. ELF связан для первых 4 КиБ внутренней SRAM. Два начальных слова задают стек и вход в Thumb-код, который маскирует прерывания, записывает маркер и остаётся в цикле. Образ предназначен для запуска отладчиком. Его сборка не требует Linux toolchain для userspace.

## Первая аппаратная проба
После согласования остановки текущей программы выбрать доступный GDB-сервер с SWD через Windows, использовать ELF именно из проверенной сборки. Остановить ядро в привилегированном Thread mode, загрузить сегменты в SRAM, выставить MSP, выбрать MSP как активный стек, выставить Thumb PC по векторам, обнулить probe_result и установить аппаратную точку останова на probe_done. Продолжить исполнение и считать слово из probe_result. Критерий TC-03 — 0x429 и остановка на probe_done. Для повторных прогонов оформить сценарий stm32-gdbtest. По окончании перезапустить штатную прошивку. Для TC-04 потребуется отдельный Linux-образ и протокол консоли.

### Пробная сборка Linux 6.14.5 в WSL

Для оценки размера собраны no-MMU xipImage (2 239 112 байт) и штатный DTB (19 564 байта) без initramfs. Исходный архив с kernel.org проверен по SHA-256. Ниже команды для каталога с распакованными исходниками linux-6.14.5 и GNU Arm Embedded GCC 10.2.1.

```sh
export ARCH=arm CROSS_COMPILE=arm-none-eabi-
curl -fsSL https://raw.githubusercontent.com/buildroot/buildroot/6824cf90ae0fb88c63f8f2f8cfde0ee105eb3317/board/stmicroelectronics/stm32f429-disco/linux.config -o .config
scripts/config --set-str INITRAMFS_SOURCE "" --set-val XIP_PHYS_ADDR 0x90000000 --set-val DRAM_BASE 0x90300000 --set-val DRAM_SIZE 0x00500000
make olddefconfig
make -j8 xipImage st/stm32f429-disco.dtb
```

Артефакты находятся в arch/arm/boot/xipImage и arch/arm/boot/dts/st/stm32f429-disco.dtb. Рабочие копии текущей сборки сохранены в out/linux-6.14.5-smoke.{xipImage,dtb,config}. Штатный DTB содержит memory@90000000 размером 8 МиБ и stdout-path serial0:115200n8. Экспериментальная конфигурация выделяет ядру рабочую RAM с 0x90300000 размером 5 МиБ. Перед загрузкой определить единое разбиение для XIP, RAM и DTB, учесть переназначение FMC из аппаратного окна 0xD0000000 и добавить минимальный initramfs. Доказательством старта служит вывод на USART1.

### Сборка минимального /init для Cortex-M4 (TC-06)

Запустить из корня репозитория в WSL. Переменная KERNEL указывает на дерево Linux 6.14.5 после пробной сборки xipImage, в котором уже есть usr/gen_init_cpio. Сборка использует тот же no-MMU профиль и карту памяти, что и TC-05.

```sh
export ARCH=arm CROSS_COMPILE=arm-none-eabi-
KERNEL=/path/to/built/linux-6.14.5
sh tools/build-initramfs.sh "$KERNEL" out
cpio -itv < out/initramfs.cpio
archive=$(realpath out/initramfs.cpio)
(cd "$KERNEL" && scripts/config --disable HZ_1000 --enable HZ_100 --set-str INITRAMFS_SOURCE "$archive" && make olddefconfig && make -j8 xipImage)
```

Архив newc содержит /dev/console (5:1) и исполняемый /init размером 148 байт. Код Thumb для ARM EABI позиционно независим и упакован в bFLT v4 с входом 0x41 и стеком 4096 байт. Процесс проверяет getpid(), отправляет контрольную строку через write(1, ...) и остаётся в pause(). Драйвер USART и настройки терминала берутся из ядра и DTB предыдущего запуска. Для опыта при HCLK 16 МГц задан CONFIG_HZ=100. Это частота системного тика Linux; SWD работает на 950 кГц, UART — на 115200 бод.

### Интерактивный BusyBox для TC-07

К ядру Linux 6.14.5 из TC-06 добавляется initramfs с BusyBox 1.36.1. В нём /init запускает /bin/sh -i, а /bin/sh и /bin/uname указывают на bFLT-бинарник BusyBox. Ввод приходит на PA10, ответ — с PA9. Хост ожидает приглашение disco#, передаёт девять байт команды uname -r с CR и проверяет отдельную строку версии и повторное приглашение.

В WSL распаковать исходники BusyBox и SDK Bootlin из карты источников, вызвать relocate-sdk.sh из каталога распакованного SDK. KERNEL, BUSYBOX и SDK ниже — абсолютные пути к собранному дереву Linux, исходникам BusyBox и SDK.

```sh
CROSS_COMPILE="$SDK/bin/arm-linux-" sh tools/build-shell-initramfs.sh "$KERNEL" "$BUSYBOX" out
cpio -itv < out/shell.cpio
archive=$(realpath out/shell.cpio)
(cd "$KERNEL" && export ARCH=arm CROSS_COMPILE=arm-none-eabi- && scripts/config --disable HZ_1000 --enable HZ_100 --disable NO_HZ_IDLE --enable HZ_PERIODIC --disable PREEMPT --enable PREEMPT_NONE --set-str INITRAMFS_SOURCE "$archive" && make olddefconfig && make -j8 xipImage)
```

Установлены bFLT BusyBox и его апплет uname. Скрипт проверяет в итоговой конфигурации no-MMU, интерактивный hush, поддержку PS1 и все запрошенные апплеты. Для загрузки применить карту TC-05. При подготовке DTB по инструкции TC-05 добавить nohlt в конец bootargs (после panic=0). Это включает непрерывный опрос вместо WFI в idle для диагностического прогона. Чтение RCC перед сеансом показало RCC_CR=0x00007d83, RCC_CFGR=0x00000000. Номинальный HSI и HCLK равны 16 МГц, PLL выключен. Паспортный предел STM32F429ZI — 180 МГц в режиме over-drive. Перенастройка PLL потребует пересчитать частоты FMC, refresh SDRAM и делители периферии. Частота отладочного SWD 950 кГц независима от HCLK.

### Сетевой профиль LAN8720 для TC-08

Начать с собранного профиля TC-07 с действующим путём к shell.cpio. В каталоге исходников Linux задать REPO равным абсолютному пути проекта. Файл /tmp/f429-first-boot.dts создаётся по инструкции TC-05 выше.

```sh
export ARCH=arm CROSS_COMPILE=arm-none-eabi-
patch -p1 < "$REPO/firmware/linux-6.14.5-stmmac-rx-align.patch"
scripts/kconfig/merge_config.sh -m .config "$REPO/firmware/linux-lan8720.config"
make olddefconfig
make -j8 xipImage
test "$(wc -c < arch/arm/boot/xipImage)" -le $((0x2f0000))
cat /tmp/f429-first-boot.dts "$REPO/firmware/lan8720.dtsi" |
  scripts/dtc/dtc -q -I dts -O dtb -o /tmp/f429-lan8720.dtb
```

Профиль задаёт плате MAC 02:42:f4:29:00:01 и IPv4 198.18.42.2/30 для изолированного сегмента. Для ПК предусмотрен 198.18.42.1. PD2 и PE3 обслуживает mdio-gpio, PHY имеет адрес 1. Ядро настраивает IPv4 при старте через ip= в bootargs.

На MB1075 B-01 до подключения REF_CLK освободить PA1 по протоколу Ethernet. При подключённом такте держать это состояние гироскопа на протяжении сеанса. Для диагностического старта FMC сначала инициализирован на штатных 16 МГц как в TC-05. После проверки загрузки в SDRAM выбран PLL от HSI с PLLM=16, PLLN=336, PLLP=4. ### Профиль SSH/SCP с загрузкой из внутренней Flash

Для стенда используются отдельный ключ хоста в формате Dropbear и публичный ключ клиента OpenSSH (Ed25519). Ключ хоста создаёт нативный dropbearkey, закрытый ключ клиента остаётся на ПК. Включённый в BIN ключ хоста делает BIN и initramfs приватными артефактами. В WSL использовать абсолютные пути без пробелов и новый каталог вывода.

```sh
sh tools/build-ssh-initramfs.sh "$KERNEL" "$BUSYBOX" "$DROPBEAR" "$SDK" \
    "$HOST_KEY" "$CLIENT_PUB" "$PRIVATE_OUT"
(cd "$KERNEL" && export ARCH=arm CROSS_COMPILE=arm-none-eabi- && \
    patch -p1 < "$REPO/firmware/linux-6.14.5-stmmac-small-rings.patch" && \
    scripts/config --set-val INET_TABLE_PERTURB_ORDER 10 --enable SLUB_TINY --enable COMPAT_32BIT_TIME --enable UNIX --enable RANDOM_TRUST_BOOTLOADER --enable IP_PNP_DHCP \
        --set-str INITRAMFS_SOURCE "$PRIVATE_OUT/ssh.cpio" && \
    make olddefconfig && make -j8 xipImage)
```

Использовать ядро и DTS TC-08 с поправкой stmmac. Для этого стенда в выбранном DTS заменить статический параметр ip= на ip=::::disco:eth0:dhcp и собрать DTB. Затем создать полный BIN:

```sh
sh tools/build-flash-image.sh "$KERNEL/arch/arm/boot/xipImage" "$DHCP_DTB" \
    "$ZLIB_ARCHIVE" "$KERNEL/scripts/dtc/dtc" "$PRIVATE_OUT/flash"
```

Линкер ограничивает FLASH двумя МиБ начиная с 0x08000000. Загрузчик в режиме Thumb настраивает FMC, включает PLL 84 МГц, разворачивает поток DEFLATE в 0x90000000 и копирует DTB в 0x902f0000. До входа в ядро проверяются длины и CRC и заполняется свойство rng-seed данными аппаратного RNG. Для MB1075 B-01 сначала отключить REF_CLK от PA1. Загрузчик программирует L3GD20 и сообщает по COM21 о готовности; при достигнутом WAIT REF_CLK можно подключить такт без Reset. Этот стендовый порядок нужен и после полного снятия питания.

Первый стендовый вариант 04.11.2026 содержал 1 811 631 байт. Текст загрузчика и начальные данные заняли 3392 байта. В поток 1 788 047 байт упаковано ядро 2 801 225 байт с initramfs; DTB занимает 20 191 байт, плюс один байт выравнивания перед DTB. Свободно 285 521 байт. Рабочая RAM Linux занимает 5 МиБ внешней SDRAM; /tmp находится в записываемой корневой ФС в той же SDRAM. Внутренние 192 КиБ SRAM и отдельные 64 КиБ CCM не требуются для хранения всего распакованного образа.

Закрытый ключ сервера генерируется один раз для конкретной платы. Пример для WSL с установленным dropbearkey и OpenSSH:


Профиль STM32 использует кольца по 64 дескриптора вместо 512, SLUB_TINY и 32 КиБ стека bFLT для сервера и scp. Для uClibc из SDK 2024.05-1 нужен COMPAT_32BIT_TIME. Отдельные вызовы времени и select в Dropbear переведены на ARM EABI time64. Без этой поправки наблюдался немедленный Timeout before auth. Срок ожидания аутентификации в Dropbear сохранён.

Тест использует порт 2222 и сохраняет на ПК конфигурацию клиента, результат uname, оба экземпляра файла и хеш платы. На новой OpenSSH выбирается протокол scp -O; в OpenSSH 8.2 SCP используется по умолчанию. Логин для ручного сеанса после успешного теста — ssh -F "$NEW_RESULT_DIR/ssh.conf" disco.
